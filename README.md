# 🌌 THE NEXT INTERFACE OF COMMERCE

The web was built for **humans**.

The next generation of commerce will increasingly be built for **agents**.

Imagine telling your AI:

```text
"Get me a mechanical keyboard and wireless mouse.
Keep the total below ₹4,000."
```

You don't search.

You don't compare twenty tabs.

You don't fill a checkout form.

Your **AI Buyer Agent** discovers the catalog, evaluates products, constructs the order and requests payment.

But there's a problem.

<br>

# 🛡️ ZERO-TRUST POLICY ENGINE

The most important rule:

> **Never trust prices, inventory or authorization data supplied by the agent.**

The gateway independently calculates the transaction.

### 🔥 Price Tampering Protection

Agent says:

```json
{
  "sku": "SKU-KB-01",
  "priceINR": 1
}
```

Gateway says:

```text
CATALOG PRICE
₹2,499

REQUESTED PRICE
₹1

❌ PRICE MISMATCH

GATE_REJECTED
```

---

### 💰 Budget Protection

```text
Agent Budget
     │
     ▼
₹4,000
     │
     ├───────────────┐
     │               │
Cart Total       ₹3,328
     │               │
     └───────<───────┘
             │
             ▼
          APPROVED
```

But:

```text
Cart Total = ₹4,998
Budget     = ₹1,500

❌ BUDGET_EXCEEDED
```

No payment order is created.

### 📦 Inventory Protection

```text

  "suggestedAction": "FIND_ALTERNATIVE"
}
```

# 🔐 CRYPTOGRAPHIC TRUST LAYER

Every transaction lifecycle produces an auditable chain.

```text
┌──────────────┐
│ GATE         │
│ EVALUATION   │
└──────┬───────┘
       │
       ▼
┌──────────────┐
│ ORDER        │
│ CREATED      │
└──────┬───────┘
       │
       ▼
┌──────────────┐
│ PAYMENT      │
│ CAPTURED     │
└──────────────┘
```

Each block contains:

```text
AUDIT ID
TIMESTAMP
EVENT TYPE
BUYER AGENT ID
STATUS
PREVIOUS HASH
CURRENT HASH
```

### Mathematical Model

```text
Hₙ = SHA256(
       ID ||
       Timestamp ||
       EventType ||
       BuyerAgentID ||
       Status ||
       Hₙ₋₁
     )
```

This creates a forward-linked integrity chain.

If an old event is modified:

```text
OLD DATA
   ↓
NEW HASH
   ↓
CHAIN MISMATCH
   ↓
🚨 INTEGRITY FAILURE
```

> Blockchain-inspired architecture for tamper-evident auditing. This implementation is not itself a distributed blockchain or a claim of regulatory certification.

# 🚨 FAILURE IS A FEATURE

Autonomous systems must fail **predictably**.

### Out-of-stock

```text
422 GATE_REJECTED
INSUFFICIENT_STOCK
```

### Budget exceeded

```text
422 GATE_REJECTED
BUDGET_EXCEEDED
```

### Invalid price

```text
422 GATE_REJECTED
PRICE_MISMATCH
```

### Invalid transaction

```text
422 GATE_REJECTED
POLICY_VIOLATION
```

The gateway transforms unpredictable payment behavior into **deterministic machine-readable decisions**.

# 🚀 QUICK START

## 01 — Clone

```bash
git clone https://github.com/Adhi426/agentic-commerce-gateway.git
cd agentic-commerce-gateway
```

## 02 — Install

```bash
npm install
```

## 03 — Environment

Create `.env.local`:

```env
RAZORPAY_KEY_ID=rzp_test_YourKeyHere
RAZORPAY_KEY_SECRET=YourSecretHere
NEXT_PUBLIC_RAZORPAY_KEY_ID=rzp_test_YourKeyHere
RAZORPAY_WEBHOOK_SECRET=your_webhook_secret
```

> ⚠️ Never commit `.env.local`.

## 04 — Run

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```
